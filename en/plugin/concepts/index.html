GReggular Concepts

A virtual instrument developed from the Greggular plugin. Its Web UI brings sound creation onto a tactile scene of objects and opens it to shared performance across devices.

Instrument and collaboration

GReggular Concepts

Concepts groups sound objects into granular centres for touch and MIDI performance. A shared LAN session lets participants join from their phones and shape the same scene together. The plugin on the host computer generates the audio.

The host shares an invite link or QR code and assigns access to selected sound groups. Several phones become control surfaces for one shared instrument.
